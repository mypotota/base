# 终端搜索命令：grep / find / rg 使用方法

> 创建于 2026-11-15 · 以 GNU grep 语法为准（各发行版通用）· 文末有本机环境说明

## 1. grep：在文件内容里找文本

基本形态：

```bash
grep [选项] '模式' 文件...
grep [选项] '模式'          # 从 stdin 读，常接在管道后面
```

### 1.1 最常用的选项

| 选项 | 作用 | 记法 |
|---|---|---|
| `-i` | 忽略大小写 | **i**gnore case |
| `-n` | 显示行号 | **n**umber |
| `-r` / `-R` | 递归搜整个目录 | **r**ecursive |
| `-w` | 全词匹配（`cat` 不会命中 `category`） | **w**ord |
| `-v` | 反选：显示**不**匹配的行 | in**v**ert |
| `-c` | 只统计每个文件匹配了多少行 | **c**ount |
| `-l` | 只列出含有匹配的文件名（大写 L 是"不含"） | **l**ist |
| `-o` | 只输出匹配到的片段本身，不输出整行 | **o**nly |
| `-E` | 扩展正则（`\|`、`+`、`?`、`()` 直接写） | **E**xtended |
| `-F` | 按纯文本搜，不解析正则（搜 `$`、`.` 这类符号时最省心） | **F**ixed |
| `-A n` / `-B n` / `-C n` | 显示匹配行的后 / 前 / 前后各 n 行上下文 | **A**fter / **B**efore / **C**ontext |
| `--color=auto` | 匹配处高亮（很多发行版已默认） | |
| `-h` / `-H` | 多文件时不显示 / 强制显示文件名前缀 | |

### 1.2 常用组合（背下这几条够用 90% 场景）

```bash
# 在单个文件里找，带行号
grep -n 'TODO' main.c

# 递归搜整个目录，只搜 .java 文件
grep -rn 'bindService' src/ --include='*.java'

# 递归搜，但跳过 .git 和 build 目录
grep -rn 'mFocusedApp' . --exclude-dir={.git,build,out}

# 忽略大小写 + 全词匹配
grep -inw 'error' log.txt

# 管道过滤：上一条命令的输出里找
dumpsys window | grep -iE 'mCurrentFocus|mFocusedApp'
ps -A | grep zygote

# 数一下匹配行数（不打开文件）
grep -c 'W/ActivityManager' logcat.txt

# 找出哪些文件含这个串（配合后续批量处理）
grep -rl 'http://' src/

# 反选：看日志里除 DEBUG 以外的行
grep -v 'DEBUG' app.log

# 看匹配处前后各 3 行上下文（读代码定位调用点）
grep -nC 3 'startActivity' ActivityManagerService.java

# 只提取匹配片段本身：从 ini 里抠出所有 key = 后面的值
grep -oE '^[a-z_]+ =' config.ini
```

### 1.3 正则速查（grep 用的是 POSIX 正则，不是 PCRE）

| 意图 | 写法（配 `-E`） | 示例 |
|---|---|---|
| 任意单个字符 | `.` | `ab.` 匹配 `abc`、`abx` |
| 任意多次 / 一次以上 / 可选 | `*` / `+` / `?` | `go+gle` 匹配 `gogle`、`google`（o ≥ 1）；`colou?r` 匹配 `color`、`colour` |
| 一组候选 | `\|`（不加 `-E` 时）或 `|`（加 `-E`） | `grep -E 'cat\|dog'` ≡ `grep 'cat\|dog'` |
| 分组 | `( )` | `grep -E '(ab)+' ` |
| 行首 / 行尾 | `^` / `$` | `^import`、`};$` |
| 字符集合 | `[ ]`，`[^ ]` 取反 | `[0-9]{3}`（`{n}` 需 `-E`） |
| 词边界 | `\<` `\>` 或直接用 `-w` | `\<cat\>` |
| 转义特殊字符 | 前加 `\` | 搜字面 `.` 写 `\.`，或不带 `-E` 时多数符号本来就是字面量 |

不写 `-E` 时是"基础正则"（BRE）：`+ ? ( ) { } |` 都要加反斜杠才生效，容易踩坑——**建议日常一律加 `-E`**，语法和主流语言一致。

### 1.4 二进制 / 压缩文件

- grep 碰到二进制文件默认只提示 `Binary file ... matches`；加 `-a` 当文本强行搜。
- 搜压缩包内容用 `zgrep`（gzip）、`zgrep` 配合 `.gz`；ugrep/ripgrep 见 §4。

## 2. find：按"文件属性"找文件

grep 找**内容**，find 找**文件本身**（名字、大小、时间）。

```bash
# 基本形态：从哪个目录开始，按什么条件，找到后做什么
find 起始目录 [条件...] [-exec 命令 {} \;]

# 按名字（-iname 忽略大小写）
find ~/aosp -name 'Android.bp'
find . -iname '*.md'

# 多条件：-o 是"或"，默认是"与"；! 是"非"
find src -name '*.java' -o -name '*.kt'
find . -name '*.tmp' ! -path './.git/*'

# 按大小：大于 100M 的文件（+是大于，-是小于，c=字节）
find ~ -size +100M

# 按修改时间：最近 1 天内改过的文件（+n 是 n 天前以前）
find src -mtime -1

# 找到后对每个文件执行命令（{} 是占位符）
find src -name '*.log' -delete
find . -name '*.bak' -exec rm -i {} \;
# 换成 + 表示把多个文件一次性塞给命令，更快
find . -name '*.java' -exec grep -l 'TODO' {} +
```

## 3. 其他找文件的途径

| 命令 | 找什么 | 示例 |
|---|---|---|
| `which` | 命令的可执行文件路径 | `which python3` |
| `whereis` | 二进制 + 源码 + man 手册 | `whereis grep` |
| `type` | shell 眼中这个命令是什么（别名/内建/文件） | `type ls` |
| `locate` | 全盘文件名数据库（快但可能过期，需 `updatedb`；本机未装） | `locate Android.bp` |
| `fd` | find 的现代替代品，语法更简洁（本机未装） | `fd Android.bp` |

## 4. ripgrep（rg）：现代版 grep，搜代码首选

本机已装 `rg`。速度快（Rust 实现、多线程、默认递归、默认尊重 .gitignore），日常搜代码比 `grep -r` 舒服得多：

```bash
# 等价于 grep -rn --exclude-dir=.git，但快得多且自动跳过 gitignore 的文件
rg 'bindService'

# 只搜 .java 文件（-t 按类型，--type-list 看全部类型）
rg -t java 'bindService'

# 显示上下文各 2 行
rg -C 2 'mFocusedApp'

# 忽略大小写、全词
rg -iw 'error'

# 只列出文件名 / 只数匹配数
rg -l 'TODO'
rg -c 'TODO'

# 用 PCRE 正则（支持前后瞻 (?=...) 等）
rg -P 'foo(?=bar)'

# 不尊重 .gitignore、搜隐藏文件（行为对齐 grep -r）
rg -uu 'pattern'
```

`fzf`（通用模糊筛选器，本机已装）：任何命令的输出接 `| fzf` 即可交互式模糊搜索选中一行，例如 `ps -A | fzf`、`history | fzf`。

## 5. 踩坑记录

- **基础正则忘了加 `-E`**：`grep 'cat|dog' file` 一条都搜不到（`\|` 才行），或者把 `.` 当通配符误命中一堆。想搜字面 `.` 用 `grep -F 'v1.2'` 最稳。
- **`grep -r` 把 .git、build 产物、二进制全搜一遍**：又慢又一堆噪音，记得 `--exclude-dir`，或直接换 `rg`。
- **把管道过滤和参数搞混**：`grep 'x' *.log` 是 grep 自己读文件；`cat a.log | grep x` 多一次无谓的 cat，脚本里直接写前一种。
- **`-c` 数的是"匹配的行数"不是"匹配次数"**：一行内命中 3 次也只计 1；要次数用 `grep -o 'x' file | wc -l`。
- **大写 L 和小写 l**：`-l` 列出**有**匹配的文件，`-L` 列出**没有**匹配的文件，急用时容易拿反。
- **find 的 `-exec` 结尾**：`\;` 是每个文件执行一次，`+` 是攒一批执行（配合 grep/grep -l 更快）；`\;` 忘写反斜杠会被 shell 吃掉。
- **find 按时间**：`-mtime -1` 是"24 小时内"，`-mtime 1` 是"第 1 天整（24–48 小时前）"，`+1` 是"48 小时以前"——边界很容易搞错。

## 7. 一页速查

```bash
grep -in 'err' app.log            # 忽略大小写 + 行号
grep -rn 'foo' src/ --include='*.kt'   # 递归搜指定后缀
grep -rl 'foo' src/               # 只要文件名列表
grep -v 'DEBUG' app.log           # 反选
grep -nC 3 'bar' file.c           # 带前后 3 行上下文
grep -E 'a|b|c' file              # 扩展正则
grep -F 'v1.2.3' file             # 纯文本字面搜索
find . -name '*.log' -mtime -1    # 最近一天改动的 .log
find src -name '*.java' -exec grep -l 'TODO' {} +
rg -t java -C 2 'bindService'     # 现代替代，默认递归+跳过 gitignore
ps -A | fzf                       # 交互式模糊筛选
```
